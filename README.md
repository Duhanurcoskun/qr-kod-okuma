# QR Kod Okuma
Python ve OpenCV ile bilgisayar kamerasından canlı görüntü alıp QR kodu algılayan ve içeriğini ekranda gösteren uygulama. Sürü İHA çalışmaları için görüntü işleme hazırlığı olarak geliştirildi.

## Özellikler
- QR kodun etrafına çerçeve çizer
- QR içeriğini ekranda gösterir
- GOREV_1, GOREV_2, GOREV_3 içeriklerini ayrıca algılar
- QR yokken "QR ARANIYOR..." mesajı verir
- q tuşuyla çıkılır

## Kurulum
pip install opencv-python

## Çalıştırma
python proje.py
